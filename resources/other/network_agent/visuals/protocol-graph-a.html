Step 5a, revised from the first draft: circuit choice and intent compilation moved from commit to reserve, because SENSE propagate already needs the full intent; the capacity recheck moved to reserve, before the ledger debit; a failed commit no longer rolls back the ledger. Step 5b adds the shared entry and exit (dedupe_request, sweep_expired, remember_response) and the release and modify branches. TTL expiry is handled lazily: every message first sweeps what has expired. The sweep gives back expired reserves with the same functions as the release branch. Implemented 2026-11-01.
